# Python Data Entry Form

A desktop data entry application built using Python and Tkinter that securely captures user details and saves them directly into an Excel spreadsheet.

## Features
- **Graphical User Interface:** Form fields for Full Name, Contact Number, Age, Gender selection (Combobox), and a multi-line Address text area.
- **Excel Integration:** Automatically checks for or creates an Excel file (`Backened_data.xlsx`) and logs entries row-by-row using `openpyxl`.
- **Form Controls:** Built-in validation, clear functionality, and confirmation/warning popups using `messagebox`.
- **Custom Branding:** Features a custom window icon configuration.

## Technologies Used
- Python 3
- Tkinter (GUI Framework)
- Openpyxl (Excel Workbook Management)
- Pillow (PIL) for image handling
